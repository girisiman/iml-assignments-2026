# 🎓 Introductory Machine Learning

Assignments from the introductory machine learning course at **MBUST**, taught by **Ms. Mamta Bhattarai**.

Four folders — one for each assignment.

## 📁 Folder structure

```
.
├── Assignment_I_and_II/              Assignment I and II
├── Assignment_III/                   Assignment III
├── Assignment_IV/                    Assignment IV
│   ├── code/                         Python files
│   ├── figures/                      plots
│   └── drafts/                       earlier drafts
└── Final_Assessment_CICIoMT2024/     final paper
```

## 📖 How to read this folder

1. Start here, then open the assignment folder you need.
2. The **PDF** in that folder is the submitted report.
3. For Assignment IV, the programs are in `code/` and the plots are in `figures/`.
4. `drafts/` is not the final submission.
